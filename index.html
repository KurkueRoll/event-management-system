ABSTRACT

The Event Management System is a web-based application designed to simplify and organize the process of planning, managing, and conducting various events. Organizing an event manually can be time-consuming and difficult because it requires proper coordination, scheduling, registration, and management of event-related information. This project aims to overcome these challenges by providing a centralized online platform for efficient event management.

The system allows users to view available events, access event details, register for events, and obtain relevant information easily. It also provides an administrator with facilities to add, update, delete, and manage event information, including event names, dates, venues, descriptions, and registrations. The system helps maintain event-related data in an organized manner and reduces paperwork and manual effort.

The main objective of this project is to develop a user-friendly, reliable, and efficient platform that improves communication between event organizers and participants. The system can be developed using web technologies such as HTML, CSS, and JavaScript for the front end, PHP for server-side processing, and MySQL for database management, depending on the project requirements.

The Event Management System provides a convenient solution for managing college functions, seminars, workshops, cultural programs, birthday parties, and other events. It helps save time, improve accuracy, and make event-related activities easier to manage.

In conclusion, this mini project demonstrates how web technology can be used to automate event management activities and provide a more systematic, organized, and accessible approach to event planning and coordination.

1. INTRODUCTION

The Event Management System is a web-based application developed to make the process of planning, organizing, and managing events easier, faster, and more efficient. In today's digital world, events such as college functions, seminars, workshops, cultural programs, birthday parties, weddings, and business meetings require proper planning and coordination. Managing these activities manually can be time-consuming and may lead to errors, confusion, and difficulties in maintaining records.

The main purpose of the Event Management System is to provide a centralized platform where event organizers can manage event-related activities efficiently. The system helps organizers create events, update event details, manage schedules, maintain participant registrations, and provide important information about upcoming events. Users can view available events and access details such as event name, date, time, venue, and description.

Traditional event management methods often involve paperwork, manual registration, and separate records for different activities. These methods can make it difficult to update information, track registrations, and coordinate with participants. The proposed system aims to reduce these problems by automating important event management tasks through a user-friendly website.

The Event Management System can include two main types of users: Administrator and User. The administrator is responsible for managing event information, updating details, and monitoring registrations. Users can browse available events, view event information, and register for events according to the features provided by the application. The system can also use a database to store event details and registration records in an organized manner.

The website can be developed using technologies such as HTML, CSS, and JavaScript for designing an interactive user interface, PHP for server-side processing, and MySQL for storing and managing data. These technologies help create a structured application that can be accessed through a web browser.

The major objective of this project is to save time, reduce manual work, improve data accuracy, and make event organization more convenient. It also provides an opportunity to understand the practical implementation of web development, database connectivity, software design, and system management.

In conclusion, the Event Management System is designed to provide a simple, organized, and efficient solution for managing events. It demonstrates how information technology can improve the planning and coordination of events while reducing the difficulties associated with traditional manual methods.

2. SYSTEM ANALYSIS

System analysis is an important phase in the development of the Event Management System. 2.2 Existing System

In the existing system, event management activities are generally performed manually using paper records, registers, telephone calls, and spreadsheets. Event organizers maintain information about event schedules, venues, participants, and registrations separately.

The manual system may work for small events, but it becomes difficult to manage when the number of events and participants increases. Updating information and maintaining accurate records can require considerable time and effort.

Disadvantages of the Existing System

- Time-consuming: Manual event planning and registration require significant time.

- Paperwork: Maintaining physical records increases administrative work.

- Data errors: Manual data entry may lead to mistakes and duplicate records.

- Difficult record management: Searching, updating, and maintaining information can be challenging.

- Communication problems: Participants may not receive updated event information on time.

- Limited accessibility: Event information may not be available online whenever users need it.

2.3 Proposed System

The proposed Event Management System is a web-based application that helps users and administrators manage event-related activities through a single platform. It aims to reduce manual work and make event information easier to access and maintain.

The administrator can add new events, update existing event details, delete events, and manage participant registrations. Users can view available events, check event details, and register for events through the website.

The system stores information in a database, making it easier to retrieve and update event records. Its interface is designed to be simple and user-friendly.

Advantages of the Proposed System

- Reduces manual work and paperwork.

- Provides centralized storage of event information.

- Makes event details easily accessible.

- Simplifies event registration and record maintenance.

- Helps administrators update event information efficiently.

- Improves the organization and management of events.

- Reduces the possibility of manual errors.

- Provides a convenient and user-friendly interface.

4.2 System Architecture

The Event Management System follows a three-layer architecture.

1. Presentation Layer

This layer provides the user interface through which users and administrators interact with the website. It includes web pages such as the home page, event listing page, registration page, login page, and admin dashboard.

Technologies: HTML, CSS, JavaScript.

2. Application Layer

This layer processes user requests, validates input, manages event-related operations, and communicates with the database. It handles activities such as adding events, updating event information, and processing registrations.

Technology: PHP.

3. Database Layer

This layer stores and manages information related to users, events, and registrations.

Technology: MySQL.

The Event Management System is tested to verify that users can view events, register for events, and access event information, while administrators can add, update, delete, and manage event details and participant registrations.

Testing helps ensure that the website is reliable, user-friendly, secure, and capable of handling the main operations required for event management.

5.2 Objectives of Testing

The main objectives of testing the Event Management System are:

1. To verify that all modules work correctly.

2. To identify and remove errors in the application.

3. To check the accuracy of data stored in the database.

4. To verify user registration and login functionality.

5. To test event creation, updating, and deletion.

6. To verify event registration and registration records.

7. To check input validation and error messages.

8. To ensure that unauthorized users cannot access administrative functions.

9. To verify that the website works properly in supported web browsers.

5.3 Types of Testing

1. Unit Testing

Unit testing checks individual components of the application separately. Each module is tested to ensure that it performs its intended function.

For example, the login module is tested to verify that valid credentials are accepted and invalid credentials are rejected. Similarly, the event management module is tested to check whether event details can be added and updated correctly.

2. Integration Testing

Integration testing checks whether different modules work correctly when connected.

In the Event Management System, integration testing verifies communication between the user interface, PHP application logic, and MySQL database. It also checks whether event registration details are correctly stored and associated with the appropriate users and events.

3. System Testing

System testing evaluates the complete application as a whole. The website is tested against the project requirements to ensure that the major functions work together correctly.

It includes testing login, event viewing, event management, registration, database operations, and navigation between web pages.

4. Functional Testing

Functional testing verifies whether each feature performs according to its requirements.

The main functions tested include:

- User registration and login.

- Displaying available events.

- Viewing event details.

- Adding, updating, and deleting events.

- Registering for an event.

- Viewing participant registration records.

- Logging out of the application.

5. Validation Testing

Validation testing checks whether the system accepts valid information and rejects invalid or incomplete input.

For example, the system should validate email formats, required fields, event dates, and login credentials before processing the information.

6. Security Testing

Security testing checks whether the application protects user information and administrative operations. It includes testing authentication, session handling, input validation, and access restrictions for administrative functions.

7. Usability Testing

Usability testing checks whether users can navigate and operate the website easily. The interface should be clear, consistent, and understandable for both users and administrators.
